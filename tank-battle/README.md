# 坦克大战（网页复刻版）

照着 FC《坦克大战》（Battle City）复刻的网页游戏，单人闯关，35 关，电脑和手机都能玩。

在线地址：https://markwcl2004.github.io/tank-battle/

## 怎么玩

- 电脑：方向键或 WASD 移动，空格或 J 开火，P 或 Esc 暂停。
- 手机：横屏竖屏都能玩。左边摇杆移动，右边按钮开火；横屏时暂停在右上角，竖屏时在底部中间。
- 在微信里打不开的话，点右上角菜单，选"在浏览器打开"。

## 账号、存档、排行榜

现在账号、存档和排行榜都**只存在当前浏览器里**（localStorage）：换设备或清浏览器数据就没了，排行榜也只有这台设备上的记录。
接上 Supabase 后才会变成云端的，届时这一节会更新。

## 本地运行

在 `tank-battle/` 目录下：

```bash
npm run serve           # 打开 http://127.0.0.1:8642/
npm test                # 单元测试
npm run check-stages    # 校验 35 关数据
node tools/smoke.mjs http://127.0.0.1:8642/ smoke-out   # 无头 Chrome 跑一遍，存截图
```

不需要安装依赖，也没有构建步骤，仓库里的文件就是线上跑的文件。
